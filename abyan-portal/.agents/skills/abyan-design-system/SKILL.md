# مهارة نظام تصميم هوية أبين الثقافية (Abyan Design System Skill)

تُستخدم هذه المهارة لتوجيه الوكيل البرمجي عند تطوير وبناء أي واجهة أو مكون لمشروع بوابة أبين.

## ☀️ النمط العام (Light Theme)
- خلفية بيضاء ناصعة (`bg-white` / `#FFFFFF`).
- نصوص بالرمادي الصخري الداكن (`#0F172A`).
- تباين عالي وجمالية عصرية دون تظليل داكن.

## 🎨 اللوحة اللونية (Strict Color Palette)

| اللون | Hex Code | فئة Tailwind | الاستخدام والرمزيّة |
|---|---|---|---|
| **الأخضر الربيعي** | `#10b981` / `#059669` | `emerald-500` / `emerald-600` | لون كلمة أبين، الأزرار الرئيسية، ورمزية دلتا بنا وحسان وسد باتيس |
| **الأزرق السماوي** | `#0ea5e9` / `#0284c7` | `sky-500` / `sky-600` | سماء أبين وشواطئ أحور وشقرة، الحدود التفاعلية، والروابط |
| **الرمادي الصخري** | `#0f172a` / `#e2e8f0` | `slate-900` / `slate-200` | لون النصوص الرئيسية (Slate 900) والحدود الفاتحة (Slate 200) |

## 🖼️ المكون الموحد للمعاينة والمراجعة (`UnifiedMediaViewer Architecture Standard`)
- **الهيكلية المعيارية الصارمة لكل بطاقة ومكون معاينة صور ومحتوى**:
  1. **الترويسة العلوية (`Header Section`)**:
     - **الإطار البصري / الصورة المربعة (`Square Image Box`)**: يستقر باليمين بعرض ملموم (`w-28 sm:w-40`).
     - **أمام الإطار (اليسار)**: التصنيف (`categoryLabel`)، الاسم أو العنوان الرئيسي (`title` بـ `h2`)، ثم **الوصف والصفة القصيرة الصريح مباشرة أسفل الاسم (`subtitle`)**.
  2. **الجسم السفلي المتمرّر (`Scrollable Body Narrative Section`)**:
     - يستوعب حصرياً **السيرة الذاتية والشرح التوثيقي التاريخي والمطوّل جداً (`fullBiography` / `description`)** المكون من فقرات ممتدة تحت عنوان ثابت: `تفاصيل القيد والتوثيق الحضاري:`.
  3. **تأمين السكرول والإطار**:
     - قفل سكرول خلفية الصفحة عند الفتح (`overflow = hidden`).
     - قص واحتواء مؤشر التمرير كلياً داخل حواف البطاقة (`rounded-3xl overflow-hidden`) مع إعطاء هامش لمسار السكرول (`margin: 16px 0`).
  4. **نص تذييل البطاقات**: يُكتب في أسفل الكروت صراحةً `معاينة ←`.

## ✒️ قواعد نظام الخطوط والطباعة (Typography Rules)
- **خط أبين والعناوين الرئيسية**: `Thmanyah Serif Display Black` (`font-abyan-title`). خام أصلي بدون `font-bold` وبدون تدرجات صبغية (No gradients / No faux bold)، مع `line-height: 1.4` و `overflow: visible`.
- **خط الفقرات والمحتوى النصي العام**: `Thmanyah Serif Display Regular` (`font-abyan-body` / `ThmanyahSerifRegular`). خط عالمي موحد لكل تاجات `<p>` ونصوص المحتوى والفقرات عبر المنصة دون استثناء.

## 📐 نظام النافبار وتخطيط موسوعة المديريات
- **النافبار**: `h-[150px]` شفاف تماماً بدون خلفية أو حدود، كلمة "أبين" باليمين وروابط النص التجريدي باليسار، ومثبت دائماً خارج نطاق `Suspense`.
- **الحاوية الذكية**: `max-w-6xl` كعرض أقصى افتراضي لحصر المحتوى وتمدد الخلفيات.
- **تخطيط موسوعة المديريات (Districts Layout)**:
  - عمود الاختيار الأيمن: بعرض ثابت ملموم قدره **`270px`** (`w-[270px] shrink-0`) وعرض انسيابي كامل بدون تمرير داخلي.
  - لوحة العرض الموسوعية الأيسر: تمتد بمرونة كاملة (`flex-1 min-w-0`).
  - نقاوة الترويسة: تحتوي البطاقات الجانبية فقط على اسم المديرية وعنوانها بدون مسميات قديمة أو تصنيفات جغرافية في ترويسة البطاقة.

## 🎛️ مكون الفئات والملاحة الأفقية (`CategoryTabSelector`)
- **التمرير على سطر واحد**: `flex-nowrap overflow-x-auto no-scrollbar` لمنع انقسام الفئات على سطرين.
- **أقواس التمرير التفاعلية (`«` و `»`)**:
  - تعمل كمتحكمات تمرير تفاعلية بالنقر والضغط المطول (`Hold to Scroll`).
  - القوس الأيمن (`«`) لترجيع التمرير نحو بداية القائمة، والقوس الأيسر (`»`) للتمرير نحو بقية الفئات.
  - محاذاة دقيقة على خط أساس النص (`leading-none font-abyan-title gap-1.5`).
  - القوس النشط بياض وضوح باللون الأخضر الربيعي (`#10b981 opacity-100 hover:text-sky-600`)، ويخفت بلطف عند الحدود (`opacity-40 text-slate-400`).
- **التوسيط التلقائي للفئة النشطة**: يتم توسيط التبويب في منتصف شريط التمرير فور اختياره.

## ⏳ نظام تصميم الخط الزمني (Abyan Timeline Component Rules)
1. **الطبقات المتراكبة والحاوية المتمردة (Layered Overlay System)**:
   - خلفية قسم الخط الزمني بالكامل **بيضاء ناصعة صافية (`bg-white` / `#FFFFFF`)** وارتفاع القسم بعرض وارتفاع الشاشة الكامل (`min-h-screen`).
   - مسار الخط الزمني يمتد أفقياً بعرض الشاشة كطبقة خلفية (`z-10`).
   - مكون لوحة المحتوى النصي المكتمل ([`EraDetailOverlay.tsx`](file:///a:/projects/Abyan/abyan-portal/src/components/landing/EraDetailOverlay.tsx)) **يلتصق تماماً بالطرف الأيمن للشاشة (`right-0`) متمصاً ومتمتداً حتى أقصى اليمين ومتمرد بالحاوية كطبقة علوية (`z-20`)**.
2. **شفافية التدرج والتوازي البصري المحكم**:
   - خلفية كرت النص تبدأ بشفافية 100% في أقصى اليسار (`from-transparent`) لتكشف المسار الزمني والدوائر المارة من خلفه، وتتدرج نحو الأبيض الناصع الصلب في اليمين (`to-white`) تحت النصوص بدون ظلال (`shadow-none`).
3. **الدوائر وتناسق الألوان**:
   - **الكرة النشطة (Active)**: أخضر ربيعي صلب ممتلئ (`bg-[#10b981] border-2 border-white scale-125 ring-4 ring-[#10b981]/25`).
   - **الكرات العادية (Inactive)**: كرة بيضاء ناصعة صلبة (`bg-white border-[3px] border-[#10b981]`).

## 🗺️ قواعد خريطة المديريات والنصوص النقية (Infographic Map & Pure Text Rules)
1. **خطوط التوصيل والمسافة الآمنة**: خطوط توصيل عالية التباين مع مسافة آمنة مفرغة (3px - 12px) تضمن عدم تقاطع أو ملامسة الخط لنصوص المديريات.
2. **المنع الصارم للأيقونات وخلفيات الكبسولات**:
   - **يُمنع استخدام الأيقونات أو الإيموجيهات** (مثل 🌾 و 📍).
   - **يُمنع استخدام خلفيات الكبسولات والحدود** البارزة حول القوائم.
   - تُعرض قوائم المحاصيل والمعالم كنصوص صافية باللون الأزرق السماوي الرسمي (`text-sky-600`) بخط `font-abyan-body` ومفصولة بـ `•`.

## 🏗️ نظام التحميل الوهمي المخصص المطابق 1-إلى-1 (Dedicated Blueprint Skeleton Rules)
- **المطابقة التخطيطية الهيكلية**: كل صفحة تملك مكون تحميل وهمي مخصص (`LandmarksPageSkeleton`, `DistrictsPageSkeleton`, `PioneersPageSkeleton`, `CulturePageSkeleton`, `EconomyPageSkeleton`, `GalleryPageSkeleton`, `AboutPageSkeleton`, `HistoryPageSkeleton`) يجسد محتواها بالضبط داخل `SmartContainer`.
- **خلو تام من الحدود والظلال**: خالية من الحدود (`border-none`) والظلال (`shadow-none`).
- **أنيميشن الشيمر والـ RTL**: أنيميشن بالاتجاه التلقائي السلس بين الأخضر الربيعي والأزرق السماوي (`animate-abyan-shimmer-rtl`) مع المكونات النصية الواقعية (`SkeletonTextLine`, `SkeletonParagraph`) بدعم `dir="rtl"`.

## 💫 نظام الأنيميشن الموحد الشامل (Global Unified Motion System)
- استخدام نظام الأنيميشن الموحد في `src/lib/animations.ts` (الانزلاق الانسيابي `UNIFIED_EASING = [0.16, 1, 0.3, 1]`، الستارة الهادئة `curtainOverlayVariants` بتوقيت `0.42s`، ظهور الأقسام `sectionFadeUpVariants` بمسافة `28px` والتحويم المجهري `subtleMicroHover` بالمقياس `1.03`).
