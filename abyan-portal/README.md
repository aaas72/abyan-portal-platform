# 🌴 بوابة أبين الثقافية (Abyan Cultural Portal)

بوابة إلكترونية وموسوعة ثقافية شاملة تستعرض تاريخ، تراث، جغرافيا، ومعالم محافظة أبين (مهد الحضارة والدلتا الخضراء) جنوبي اليمن، مبنية بأحدث تقنيات الويب بنمط فاتح ناصع ونظام طباعة عربي محلي فاخر.

---

## 🌟 أبرز المميزات (Features)

- ☀️ **النمط الفاتح والشفاف الناصع (Light Theme)**: تصميم عصري باللون الأبيض الناصع (`#FFFFFF`) والرمادي الصخري (`#0F172A`).
- 🎨 **هوية لونية تراثية**: اعتماد الأخضر الربيعي (`#10b981`) لرمزية دلتا بنا وحسان، والأزرق السماوي (`#0ea5e9`) لرمزية الشواطئ وسماء أبين.
- ✒️ **نظام طباعة مخصص فريد**:
  - خط **`Thmanyah Serif Display Black`** لاسم أبين والعناوين الرئيسية.
  - خط **`Thmanyah Serif Display Regular`** للفقرات ونصوص المحتوى النصي العام.
- 🏛️ **موسوعة المديريات الشاملة**: استعراض تفاعلي لمديريات أبين الـ 11 مع تقسيم تبويبي للمسار التاريخي، الجغرافيا، المعالم، الأعلام والرواد، الاقتصاد والزراعة، الثقافة، والقرى.
- 🎛️ **مكون ملاحة فئات تفاعلي (`CategoryTabSelector`)**: تمرير أفقي على سطر واحد مع أقواس نصية تفاعلية (`«` و `»`) بالنقر والضغط المطول والتوسيط التلقائي للفئة النشطة.
- ⏳ **الخط الزمني لتاريخ أبين**: عرض تفاعلي للحقبات التاريخية بنظام الطبقات المتراكبة وحجم الشاشة الكامل.
- 🎵 **مشغل الموروث الشعبي والإنشاد**: استماع وتصفح لجمال الدان والأهازيج الأبينية الأصيلة.
- 🗺️ **خريطة الإنفوجرافيك التفاعلية**: استعراض المعالم والحدود بدون أيقونات صبغية أو خطوط سفليّة مع تباين نصي نقي.

## 🚀 التقنيات المستخدمة (Tech Stack)

- **الإطار البرمجي**: [Next.js 15 (App Router)](https://nextjs.org/)
- **المكتبة الأساسية**: [React 19](https://react.dev/)
- **لغة البرمجة**: TypeScript
- **نظام التنسيق**: Vanilla CSS + [TailwindCSS v4](https://tailwindcss.com/)
- **التحريك والأنيميشن**: [Framer Motion](https://www.framer.com/motion/)
- **الخطوط**: `next/font/local` + Google Fonts (Amiri, Cairo)

## 💻 التشغيل المحلي (Getting Started)

1. **استنساخ المستودع**:
```bash
git clone https://github.com/aaas72/abyan-portal.git
cd abyan-portal
```

2. **تثبيت الحزم والمكتبات**:
```bash
npm install
```

3. **تشغيل سيرفر التطوير**:
```bash
npm run dev
```

4. فتح المتصفح على العنوان: `http://localhost:3000`

## 📂 الهيكلية البرمجية (Project Structure)

```
abyan-portal/
├── public/
│   ├── fonts/           # الخطوط المحلية (Thmanyah Serif Display)
│   └── images/          # الشواهد والصور التراثية والجغرافية
├── src/
│   ├── app/             # مسارات الصفحات (Next.js App Router)
│   ├── components/      # المكونات التفاعلية (Layout, Landing, UI, Cards)
│   ├── data/            # البيانات الموسوعية والمعالم والمديريات
│   ├── lib/             # نظام الأنيميشن الموحد (animations.ts)
│   └── services/        # خدمات جلب وتصفية البيانات (portalService.ts)
└── .agents/             # دستور الهوية البصرية ونظام مهارة أبين
```
